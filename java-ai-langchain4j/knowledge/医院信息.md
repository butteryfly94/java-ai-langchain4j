# 南京鼓楼医院概况

南京鼓楼医院（南京大学医学院附属鼓楼医院）创建于1892年，是中国最早的西医院之一，为国家区域医疗中心、江苏省三级甲等综合医院。医院现有床位3000余张，职工5000余人，其中高级职称人员800余名。

医院地址：南京市鼓楼区中山路321号。地铁1号线鼓楼站4号出口步行约500米即达。

## 就医时间

门诊时间：周一至周五上午8:00-12:00，下午14:00-17:30；周六上午半天门诊（8:00-12:00）。急诊24小时开放。

挂号方式：支持医院官方APP、微信公众号、院内自助机、人工窗口四种方式挂号。专家号源每日上午7:30统一放号，可提前7天预约。

## 就医流程

初诊患者流程：挂号（或线上预约取号）→ 分诊台报到 → 候诊叫号 → 医生问诊 → 缴费检查（如需）→ 复诊看报告 → 取药离院。建议初诊患者提前30分钟到达医院完成报到。

复诊患者可通过医院APP在线复诊，医生在线开具处方后药品可快递到家。

## 特色医疗中心

医院拥有多个国家级重点学科：骨科（脊柱外科全国领先）、普外科、生殖医学中心（试管婴儿成功率居全国前列）、心胸外科、内分泌科。疑难重症患者可申请多学科联合门诊（MDT），由三个以上相关科室专家共同制定诊疗方案。

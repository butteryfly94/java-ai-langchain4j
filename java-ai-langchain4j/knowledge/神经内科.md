# 神经内科就诊指南

## 常见疾病与症状

神经内科主要诊治以下疾病：

1. **脑血管疾病**：脑梗死（中风）、脑出血、短暂性脑缺血发作（TIA）。预警信号包括突发口角歪斜、一侧肢体无力麻木、言语不清、剧烈头痛、视物模糊，出现任一症状应立即拨打120或前往急诊，卒中绿色通道可优先进行溶栓治疗，溶栓时间窗为发病后4.5小时内，越早治疗效果越好。
2. **头痛头晕**：偏头痛、紧张性头痛、眩晕症。长期反复头痛建议完善头颅MRI排查器质性病变。
3. **癫痫**：反复发作的肢体抽搐、意识丧失，需规律服用抗癫痫药物，不可自行停药。
4. **帕金森病**：手抖、动作迟缓、肌肉僵硬、行走小碎步，早期规范用药可显著改善生活质量。
5. **睡眠障碍**：失眠、早醒、白天嗜睡，可进行多导睡眠监测明确病因。

## 检查项目

- 脑电图（EEG）：癫痫、脑炎诊断，检查前需洗头，检查约40分钟。
- 头颅MRI：脑血管病、肿瘤排查，体内有心脏起搏器或金属植入物者需提前告知医生。
- 经颅多普勒（TCD）：评估脑血管血流速度。
- 肌电图：周围神经病变、肌病诊断。

## 就诊建议

初诊建议挂神经内科普通号完成基础检查，检查结果异常或病情复杂再转专家门诊。专家门诊出诊时间：周一周三上午为脑血管病专家，周二全天为癫痫专家，周四上午为帕金森病专家。

## 常用药物说明

- 阿司匹林肠溶片：脑梗死二级预防，餐前服用，注意观察有无黑便、牙龈出血。
- 阿托伐他汀：调脂稳斑，晚间服用，定期复查肝功能与肌酶。
- 左旋多巴（美多芭）：帕金森病治疗，餐前1小时或餐后1.5小时服用效果最佳。

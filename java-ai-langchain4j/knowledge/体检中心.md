# 体检中心与预防保健

## 体检套餐

- **基础套餐（约500元）**：血常规、尿常规、肝肾功能、血糖血脂、心电图、胸片、腹部B超。适合35岁以下人群年度体检。
- **标准套餐（约1200元）**：基础套餐基础上增加头颅CT、心脏彩超、颈动脉超声、肿瘤标志物筛查、幽门螺杆菌检测。适合35-50岁人群。
- **深度套餐（约2800元）**：标准套餐基础上增加头颅MRI、胃肠镜、低剂量肺部CT、甲状腺乳腺结节筛查。适合50岁以上或有家族肿瘤史人群。

## 体检须知

体检前三天保持清淡饮食，禁酒；前一晚20:00后禁食，可少量饮水；体检当日早晨空腹，携带身份证。女性经期避免尿检与妇科检查，备孕或怀孕人群禁止X光与CT检查。

体检报告一般3-5个工作日出具，可在医院APP查看电子报告。报告异常项目建议携带报告至相应专科门诊复诊。

## 疫苗接种

预防保健科位于门诊楼1楼，提供成人疫苗接种服务：流感疫苗（每年9-11月接种，60岁以上老人优先）、HPV疫苗（9-45岁女性，需预约）、乙肝疫苗、带状疱疹疫苗（50岁以上）。接种需提前在APP预约，接种后留观30分钟。

## 慢病管理

高血压、糖尿病患者可至慢病管理门诊建立健康档案，享受用药指导、定期随访、并发症筛查一体化服务。高血压患者建议每日早晚测量血压并记录；糖尿病患者建议每3个月复查糖化血红蛋白，每年检查眼底与尿微量白蛋白。

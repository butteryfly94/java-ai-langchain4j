# 医院科室介绍

## 内科系统

- **神经内科**：诊治脑血管疾病、癫痫、帕金森病、头痛头晕、失眠等神经系统疾病。位于门诊楼3楼。
- **心内科**：诊治冠心病、高血压、心律失常、心力衰竭。位于门诊楼2楼，设有胸痛中心绿色通道，急性胸痛患者优先救治。
- **消化内科**：诊治胃炎、胃溃疡、肝炎、胰腺炎，开展胃肠镜检查。位于门诊楼3楼。
- **内分泌科**：诊治糖尿病、甲状腺疾病、肥胖症、骨质疏松。位于门诊楼4楼。
- **呼吸内科**：诊治肺炎、哮喘、慢阻肺、肺结节。位于门诊楼2楼。

## 外科系统

- **骨科**：诊治骨折、颈椎病、腰椎间盘突出、关节疾病。脊柱外科为国家级重点学科，位于住院部1号楼5楼。
- **普外科**：诊治阑尾炎、疝气、胆囊疾病、甲状腺肿瘤。位于住院部1号楼3楼。
- **心胸外科**：开展心脏搭桥、瓣膜置换、肺部手术。位于住院部2号楼4楼。
- **泌尿外科**：诊治肾结石、前列腺疾病、泌尿系肿瘤。位于住院部1号楼4楼。
- **神经外科**：诊治脑肿瘤、脑外伤、脑血管畸形。位于住院部2号楼6楼。

## 妇产科与儿科

- **妇产科**：产科（孕产保健、分娩）、妇科（肿瘤、炎症、内分泌）位于门诊楼5楼。
- **儿科**：诊治14岁以下儿童疾病，位于门诊楼1楼，设有儿童急诊专区。

## 其他科室

- **皮肤科**：门诊楼1楼。**眼科**：门诊楼4楼。**口腔科**：门诊楼4楼。**耳鼻喉科**：门诊楼3楼。
- **中医科**：门诊楼6楼，提供针灸、推拿、中药调理。
- **康复医学科**：康复楼1楼，开展术后康复、神经康复。
